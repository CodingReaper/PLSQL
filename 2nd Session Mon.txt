1. Adaptive Planning REST APIs are used to access data and supported functionalities within Workday Adaptive Planning.

2. Oracle Planning/PBCS REST APIs are used to perform supported operations within Oracle EPM Planning. They are not a direct connector to Workday Adaptive Planning.

3. To integrate the two systems through APIs, we would need an integration layer/script that calls the Adaptive API, processes the data, and then sends it to PBCS using the Oracle API.

4. Alternatively, we can continue with the existing file-based approach:
   Adaptive → CSV/TXT → Shared Path → EPM Jumpbox → EPM Automate → PBCS

5. The Adaptive team should provide/validate the Adaptive API, including the endpoint, authentication, required parameters, and data response. The EPM team can then handle the PBCS-side loading/integration.
